Harness output the sanitiser and outcome_of are tested against.

Each format is either "captured" (real output, with its source) or "known vendor
format, not reproduced" (built in the tests from the vendor's documented shape;
never call those real samples).

captured
  claude-p-instruction-a.txt        `claude -p` instruction turn (a run on this machine);
                                    answer, OUTCOME: block, then one RUNTIME: line. Nothing else follows.
  claude-p-instruction-b.txt        the same shape, a second run.
  claude-p-answer-quoted-tags.txt   a `claude -p` answer that quotes `<tool_call>` inside inline
                                    code on purpose. Byte-for-byte: it must come through unchanged.
  codex-exec-outcome.txt            `codex exec` (v0.157.0) live capture, 2026-09-26, run on this machine:
                                    codex exec --cd <dir> "<2+2 sentence, then OUTCOME: done ...>".
                                    Banner, hook lines, answer, OUTCOME:, then `hook: Stop` lines,
                                    `tokens used`, the count, and an echo of the final message.
  Source: Claude Code transcripts from this machine, supplied by the manager (runs 320, 331, 336).
  No tool-call markup appears in any of them: Claude's text output ended cleanly after the answer.
